# BL-06 — Exibir feedback contextual dos tratamentos no Laboratório

- **Prioridade:** P1
- **Status:** DONE
- **Visão:** Visão de Produto · Limpeza de Balões
- **Responsável:** A definir

**Objetivo:** Apresentar feedback de execução dos tratamentos no Laboratório, sem inventar percentuais nem alterar o processamento.

**Critério de Aceite:**
- [x] Exibir feedback de execução usando uma única instância do componente compartilhado `createJobProgress()` no rodapé fixo do Laboratório.
- [x] Identificar o tratamento ativo como Degradê, Artístico ou Suave e ocultar o feedback ao concluir ou falhar.
- [x] Usar estado indeterminado quando a execução não fornece percentual real; não simular progresso nem converter HTTP 200 em 100%.
- [x] Preservar imagens e estados finais dos quadros e remover indicadores redundantes de execução neles.
- [x] Remover dos três botões a legenda permanente `Selecione uma página e pelo menos uma área.` e manter a validação existente.
- [x] Preservar a autorização explícita de componentes adiados no Degradê e o escopo por imagem, ROI, componentes e execução.
- [x] Evitar que encerramentos atrasados ocultem a barra de outra execução e remover a instância ao sair da tela.
- [x] Corrigir a apresentação indeterminada para não animar a faixa azul em direções alternadas; manter o progresso determinado inalterado.

**Restrições (o que NÃO fazer):**
- Não inventar percentuais.
- Não tratar cancelamento da requisição do navegador como cancelamento do worker.
- Não alterar regras de elegibilidade nem processamento dos tratamentos.

**Links de Referência:** `central_v2/frontend/texto_off/laboratorio/view.js`; `central_v2/frontend/texto_off/laboratorio/degrade.js`; `central_v2/frontend/texto_off/laboratorio/tratamentos.js`; referência visual anexada ao pedido.

**Encerramento:** validado com testes direcionados e conferência visual. Os tratamentos não disponibilizam atualmente progresso percentual confiável de ponta a ponta; por isso, o Laboratório apresenta estado indeterminado sem percentual fictício. A integração de percentuais reais não foi incluída neste encerramento.
