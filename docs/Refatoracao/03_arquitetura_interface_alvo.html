Regras de engenharia incorporadas

1 · Limite de tamanhoAté ~200 linhas é o alvo. Ultrapassou: revisão arquitetural obrigatória. Se houver mais de uma responsabilidade, decompor.
2 · Sem nomes redundantesO contexto da pasta já comunica o domínio. Preferir am3_page.js a nomes longos/repetitivos.
3 · Shared não vira monólitoTabela, zoom, viewer, pager, focus, modal e toolbar permanecem componentes independentes.
4 · Página compõeA página contém somente comportamento específico e configura componentes compartilhados.
5 · CSS segue o mesmo princípioTokens/layout/componentes compartilhados; CSS local apenas para particularidades reais da página.
6 · Backend preserva domínioOrquestração coordena; processamento/ executa. Não duplicar a mesma responsabilidade nas duas camadas.
Importante: 200 linhas é um gatilho de revisão, não autorização para cortar uma função arbitrariamente. A decomposição deve respeitar SRP, coesão e contratos.
