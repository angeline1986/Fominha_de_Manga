## JSONs do repositório versus JSONs do acervo

O repositório contém 20 arquivos `.json` encontrados pela busca estática ampla, incluindo configurações, lockfile, evidências documentais e conteúdo do submódulo; não são 20 manifests da Onda 1. Entre os JSONs de implementação relevantes estão o registry de migração e `central_v2/runtime/bubble_sommelier/package.json`/lockfile. `gui_config.json` local está ignorado e seu conteúdo não foi lido. `reports/experimentos/textoff_especiais_v2` é uma árvore operacional ignorada que foi inventariada separadamente, sem alterar seu conteúdo.

## Pontos que exigem validação de schema

- Um nome, como `clean-manifest.json`, aparece em diferentes contratos; classificar por caminho, `schema`, stage e producer, nunca pelo basename isolado.
- A frequência de atualização por capítulo não é inferível com segurança de uma única fotografia.
- Hash de manifest pode encadear dependências; a transferência ao banco deve preservar a revisão analisada e a cadeia histórica, não apenas copiar campos.
- JSON de execução, JSON de evidência e JSON de autoridade devem manter classificações separadas.
- Destinos nesta tabela são propostas conceituais para M2, não decisões de schema.
