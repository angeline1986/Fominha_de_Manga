# Gestão documental

Backlog, tickets e evidências de auditoria são gestão do trabalho, não especificação de algoritmo. O destino proposto para cada grupo está no [plano de migração](../organizacao_limpeza_baloes.md). Nenhum arquivo será apagado como parte da reorganização; snapshots de backlog e evidências devem conservar data, origem e finalidade.
