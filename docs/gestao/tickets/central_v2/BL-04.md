# BL-04 — Confirmar a origem das imagens enviadas ao Drive

- **Prioridade:** P1
- **Status:** DONE
- **Visão:** Visão de Produto · Integração entre features
- **Responsável:** A definir

**Objetivo:** Confirmar qual saída do Texto Off deve alimentar o conteúdo enviado ao Drive.

**Critério de Aceite:**
- [x] Registrar em [ADR-001](../../../arquitetura/adr/ADR-001-origem-exportacao-texto-off.md) que a origem aprovada é o Consolidado Final.
- [x] Conferir a origem selecionada no código, em teste com fontes distintas e em simulação de uma página da obra.
- [x] Validar os 65 manifestos e os hashes das 1.220 páginas elegíveis de `comix/Gazing at you_v2`, sem divergências.

**Resultado:** a exportação lê `07_CONSOLIDADO_FINAL/<capítulo>/` e mantém `textoff_merged` somente como chave interna da API. A interface agora identifica a origem real. O exportador confere hashes entre simulação e cópia; a validação do manifesto em cada exportação não faz parte deste ticket.

**Restrições (o que NÃO fazer):**
- Não alterar o exportador por hipótese.
- Executar validação de exportação somente com autorização e obra disponível.
