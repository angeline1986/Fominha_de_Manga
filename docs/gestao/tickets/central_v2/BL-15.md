# BL-15 — Definir Glass como origem padrão no Laboratório

- **Prioridade:** P2
- **Status:** DONE
- **Visão:** Limpeza de Balões
- **Responsável:** A definir

**Objetivo:** Abrir o Laboratório com a saída persistida do Auto-Cleaner Glass (Transparência Básica) como origem padrão.

**Critérios de Aceite:**
- [x] Ao abrir o Laboratório, o controle de origem mostra GLASS como opção ativa.
- [x] A lista inicial usa imagens `*_clean.png` do Glass e apresenta somente páginas marcadas como `outro` no Check.
- [x] Trocar manualmente para IMG ou MERGE continua funcionando durante a sessão.
- [x] CHECK também pode ser escolhido manualmente para consultar as páginas “Outro” revisadas.
- [x] A alteração fica restrita à navegação do Laboratório.
