# BL-16 — Exibir a data da última execução do Auto-Cleaner

- **Prioridade:** P2
- **Status:** TODO
- **Visão:** Limpeza de Balões
- **Responsável:** A definir

**Objetivo:** Mostrar na tela do Auto-Cleaner quando cada capítulo foi processado pela última vez, para a etapa correspondente.

**Diretriz de implementação:** Registrar a conclusão bem-sucedida no manifesto JSON já existente da etapa, em formato ISO 8601 UTC (por exemplo, `completed_at`). Incluir o valor na resposta da listagem já carregada pela tela, sem criar uma consulta por capítulo ou ler arquivos de imagem. Exibir a data e hora convertidas para o fuso local.

**Critérios de Aceite:**
- [ ] Cada capítulo exibe a data e hora da última execução bem-sucedida do Auto-Cleaner Nível I.
- [ ] O horário é armazenado em UTC e apresentado no fuso local da interface.
- [ ] Capítulos com manifestos antigos sem data mostram um estado claro de data indisponível; não inferir a execução pelo `mtime` dos arquivos.
- [ ] A listagem obtém a data junto dos dados que já consulta, sem chamadas adicionais por capítulo nem leitura de imagens.
- [ ] O campo é atualizado apenas na geração normal de um novo manifesto, sem reescrever manifestos antigos apenas para preencher datas.
- [ ] O dado representa a última execução, sem exigir histórico completo nem banco de dados.
