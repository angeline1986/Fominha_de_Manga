# Histórico documental

Preservar aqui decisões e artefatos que explicam versões anteriores, sem tratá-los como contrato atual. Os arquivos históricos podem conter planos que não foram implementados, hipóteses, resultados de obras específicas ou descrições superadas.

Antes de mover os arquivos legados, consulte o [mapa de inventário e migração](../organizacao_limpeza_baloes.md). Até a conclusão da revisão desse mapa, os documentos continuam nos caminhos originais para não quebrar links existentes.
